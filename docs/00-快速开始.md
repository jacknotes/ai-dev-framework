# 快速开始 —— 3 步启动

> **这是唯一的用户入口文档。** 目标：不读其他任何文档，5 分钟从零到项目开工。
> 原理与规范在 `docs/01`（规则）、`docs/03`（设计原因）、`docs/04`（门禁契约）——需要时再看。

## 3 步启动

### 第 1 步：说出你的需求（在框架仓库的 agent 会话里）

> 「我想做一个订单管理系统，前后端分离，Web 界面」

AI 会对照 5 套技术栈模板（react-python / vue-go / java-spring / dotnet / jsp-servlet）
推荐最合适的一套并说明理由，**你确认后**才生成项目：

```powershell
# AI 帮你执行的（或你自己跑）：
powershell -ExecutionPolicy Bypass -File tools\new-project.ps1 -Name 订单系统 -Stack react-python -Path D:\ai\订单系统
```

生成的项目完全独立，自带 AI 手册（AGENTS.md）、五道门禁、CI、隔离环境。

### 第 2 步：到新项目里问「这是个什么项目」

在新项目目录打开 agent 会话（AGENTS.md 会自动注入），问：

> 「当前是什么项目？用哪些智能体协同工作？」

AI 会介绍项目定位与技术栈，并**推荐三档团队让你选**：

| 档位 | 智能体数 | 适用 | 花费 |
|---|---|---|---|
| quickfix | 2 | bug 修复、文案、小改动 | 最低 |
| **feature**（默认推荐） | 7 | 常规功能开发 | 中 |
| full | 9+安全红队 | 鉴权/支付/存储变更、发版前 | 最高 |

**第 2.5 步（AI 自动引导）**：AI 会检查 git 是否初始化（版本管理的硬前提，没有它流水线无法交接状态），
未初始化时经你确认执行 `git init` + 首次提交。

### 第 3 步：环境就绪 → 说「开始」

开发/测试环境定义在 `deploy/`（**强依赖**，未就绪不能开工）。AI 检测到未就绪时，
经你确认后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File deploy\install.ps1
```

自动完成：探测工具链 → 有 Docker 走 Docker、无则本机方案 → 装依赖 → 启动 → 五道门禁。
退出码 0 = 就绪且全绿。

**就绪标志（本机用户一定可访问）：**

| 服务 | 本机地址 | 用途 |
|---|---|---|
| 前端 | http://127.0.0.1:13000 | 浏览器直接打开看效果 |
| 后端 API | http://127.0.0.1:18080 | curl /health 或接口调试 |
| 数据库等 | 见 `deploy/docker-compose.yml` 注释 | psql/客户端直连 |

全部只绑 127.0.0.1：**你自己能用，局域网进不来**。

然后对 AI 说「**开始**」——选定档位的智能体按流水线干活：编码 → 门禁（真实退出码）→ 评审 → 测试 → 部署 staging。你只在三个点介入：定目标 / 关键门禁审批 / 最终验收。

## 日常使用（开新功能/修 bug 只需两句话）

```
你：「按 docs/requirements.md 的 FR-6 实现，验收标准是 XXX」
AI：（按选定档位干活）→ 门禁全绿 → 交付报告
```

写需求记住一条：**验收标准必须可测**（"返回 200 + token 字段" ✓，"界面友好" ✗）——
门禁是机器判定的，不可测的标准无从判定。

团队档位可随时换：小修复对 AI 说「用 quickfix 档」，大变更说「用 full 档」。

## 常用命令速查（不想对话时手动执行用）

```powershell
# 建项目
powershell -ExecutionPolicy Bypass -File tools\new-project.ps1 -Name 项目名 -Stack react-python -Path D:\ai\项目名

# 环境一键安装/验证（项目目录内）
powershell -NoProfile -ExecutionPolicy Bypass -File deploy\install.ps1          # 装资源+启动+五道门禁
powershell -NoProfile -ExecutionPolicy Bypass -File deploy\docker\verify.ps1   # 只重跑五道门禁
powershell -NoProfile -ExecutionPolicy Bypass -File deploy\docker\down.ps1     # 销毁环境（用完即毁）

# 框架自身自检（改了框架文件后）
powershell -ExecutionPolicy Bypass -File tools\verify-framework.ps1
```

门禁红了怎么办：`bash scripts/lint.sh 2>&1 | tail -40`——脚本末行就是真实原因，贴给 AI 修。
