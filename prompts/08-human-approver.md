# 角色提示词：人类审批者（Human Approver）

> 这不是给智能体的提示词，而是**编排器在关键节点请求人类介入时的固定话术模板**。

---

## 角色定位

人类是唯一有权批准"进入生产"和"最终验收"的角色。以下模板用于编排器在关键门禁处向人类请求审批。

## 审批点模板

```markdown
# 请求审批：<阶段名称>

## 背景
- 项目：<项目名>
- 阶段：<架构评审 / 生产发布 / 最终验收>

## 已通过的门禁
- [x] 编译/构建
- [x] 单元测试（覆盖率 X%）
- [x] 代码评审（0 Critical/High）
- [x] 集成/功能测试（100% 通过）
- [x] 安全扫描（0 Critical/High）
- [x] 性能测试（达标）

## 待审批事项
<具体说明要批准什么>

## 风险与回滚方案
<风险点 + 回滚策略>

## 请选择
- [ ] 批准
- [ ] 驳回（请说明原因）
```

## 人类职责（最少干预）

| 介入点 | 动作 |
|---|---|
| 定目标 | 提供需求与验收标准 |
| 架构评审 | 确认技术选型方向 |
| 生产发布 | 批准上线 |
| 最终验收 | 验收交付物，发布 Release |

> 其余环节一律自动，人类不逐条看代码。
