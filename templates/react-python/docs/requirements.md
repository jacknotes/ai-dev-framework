# 需求文档 — React + Python 最小示例工程

## 1. 背景与目标

提供 React 18（前端）+ Python FastAPI（后端）的最小可运行示例，作为 AI 多智能体协同开发框架的 POC 起点。

## 2. 用户故事

- 作为**用户**，我希望访问首页时能看到后端返回的问候语，以验证前后端联通。
- 作为**运维**，我希望后端有健康检查接口，以验证服务存活。

## 3. 功能需求

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-1 | 后端健康检查接口 | P0 | GET /health 返回 200，body 含 `{"status":"ok"}` |
| FR-2 | 后端问候接口 | P0 | GET /api/v1/greeting 返回 200，含 `message` 和 `time` 字段 |
| FR-3 | 前端展示问候语 | P0 | 页面加载后请求 /api/v1/greeting 并显示 message |
| FR-4 | 前端异常处理 | P1 | 接口失败时页面显示错误信息，不白屏 |

## 4. 非功能需求

- 后端单测覆盖核心接口。
- 前端单测覆盖成功/失败两种渲染路径。
- 前后端均可通过 Docker 在隔离环境运行。

## 5. 澄清问题与假设

- 假设仅需本地/隔离环境运行，不涉及鉴权。
- 假设后端端口 8000，前端 dev 端口 3000。
