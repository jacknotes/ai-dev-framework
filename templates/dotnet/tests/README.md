# tests/ —— 独立测试与安全智能体的领地

> **开发智能体不得修改本目录**（见 docs/01 §2 角色权限、AGENTS.md 目录职责）。

- `tests/e2e/`          端到端 / UI 用例
- `tests/performance/`  性能压测用例

约定：
1. 每条用例必须能追溯到 `docs/requirements.md` 的验收标准编号。
2. 必须在隔离环境运行，绝不连生产库、绝不使用真实用户数据。
3. `scripts/e2e.sh` 检测到 `tests/e2e/` 有真实用例后才执行；当前为空，脚本会**明确跳过**（不是"通过"）。

> 说明：本目录为占位骨架。真实 e2e 用例由独立测试智能体编写，开发智能体不得代替。
